DUE & SPEND - install as a phone app (PWA)

1. Put these 5 files in one folder on any free HTTPS host:
   index.html, manifest.json, sw.js, icon-192.png, icon-512.png
   - GitHub Pages: new repo > Add file > Upload files > Settings > Pages > Deploy from branch (main, root)
   - or Netlify Drop / Cloudflare Pages (drag the folder in)
2. Open the site link in Chrome on your Android phone.
3. Menu (three dots) > Install app (or Add to Home screen).
4. It opens full screen with its own icon and works offline.

Move your data: in the old page tap "Backup or restore data" > Copy, then paste it into the same screen in the installed app and tap Restore. Attached files are not part of the copy; re-attach them.
