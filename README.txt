DUE & SPEND - install as a phone app

1. Upload ALL files in this folder to your GitHub repo (Add file > Upload files).
   They replace the old ones: index.html, manifest.json, sw.js, icon-192.png, icon-512.png
2. Wait 1-2 minutes, open https://YOURNAME.github.io/REPO/ in Chrome.
3. Menu (three dots) > Install app. Close and reopen the app once or twice to load updates.

QUICK ADD
- Long-press the app icon: "Add expense" and "Add income" shortcuts.
- Extra one-tap icon: open https://YOURNAME.github.io/REPO/?add=out in Chrome,
  menu > Add to Home screen > Create shortcut. Name it "Add expense".
  Do the same with ?add=in for income.
